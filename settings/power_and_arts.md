## [ART-1] 一、仙力在主宇宙的形態

【公開】仙力進入主宇宙後，是一種**不具質量與體積的高能粒子**，視覺上類似自發微光的氣體。

【公開】進入後會如氣體般擴散，但**不會無限制溢散**。可視為一種放射性氣體：具有半衰期，約**十億年**後由高能粒子直接轉化為電磁波並消失。

【公開】**靈氣濃度存在**。自裂隙溢散的仙力具有一定範圍。

---

## [ART-2] 二、吸收與轉化

【公開】仙力的轉化基本上需要**具有生命的容器**。

【公開】例外：特定礦物晶格可以取代生命容器，使仙力在漫長時間中穩定；仙石與人造容器皆以此為基礎。見《網道與科技體系》第四、五節。

【公開】仙力進入可被認定為生命的容器中一定時長後（**時長依物種而異**），會由高能態轉為穩定態，即可被吸收。**吸收地點依種族而異。**

【公開】**神魂足夠強大可提高吸收效率**。神魂不強的種族（如泰坦族），乃至完全無法修煉的動植物，只要浸泡在足夠濃度的仙力中，身體都會自然吸收並儲存於肌肉、骨骼之中。

【公開】具備神魂或掌握正確吸納之法的修煉者，可以加速這個過程。

轉化後的能量即為**靈力**；至第八境羽化境，靈力開始朝仙力進化，法術成為仙術。見《修仙境界與戰力體系》。

## [ART-3] 三、再轉化與法術

【公開】中性的仙力被轉化儲存後，會帶有**使用者的特性**。

【公開】輸出的重點在於「**如何再轉化**」——如何將自身的能量轉化為目標方法，無論是能量攻擊或物質攻擊。

【公開】法術依靠的是**規律與對世界的理解**：這個效果如何在真實世界達成？如何精確引導體內的能量復刻它，甚至做出變化？

此即「越高階越需要理解規律」的機制根源：低階只是輸出能量，高階是在真實世界中復刻一個現象；理解越深，可復刻的現象越複雜。

## [ART-4] 四、種族特例的機制

以下三例並非破例，而是同一套底層邏輯的不同走法。

### [ART-4.S1] 獸人：俺尋思

【GM】獸人跳過的是「個體容器」這一環——**集體意念本身就是容器**，菌落即一個共同的轉化場。

【GM】因此「信念之力直接在主宇宙顯化」，是由於再轉化並非發生在某個獸人體內，而是發生在群體所在的空間中。這也解釋了他們何以難以與仙界交互：整個流程從頭到尾都在主宇宙內完成。

### [ART-4.S2] 地神族：迷你裂隙

【GM】神經中樞直連仙界、每個個體都是迷你裂隙，代表他們**省略了「等待仙力穩定」的時長**——仙力從裂隙直出，即時進入可轉化狀態。

【GM】代價是每個個體都是一個永久的通道，仙界得以直接觸及其中樞。這正是星神能將整族化為傀儡的路徑。

### [ART-4.S3] 花精族：神紋

【限定】神紋為縮短穩定時長、提高轉化效率的結構，走的仍是**標準路徑**，只是效率參數更好。

## [ART-5] 五、功法模板

功法要回答的是：仙力從進入到輸出的整條路徑，這門功法怎麼走。

| **#** | **欄位** | **內容** |
| :-- | :-- | :-- |
| 1 | 基本資料 | 名稱、淵源（時代、種族、勢力）、適用種族與路線、傳承限制 |
| 2 | 吸納 | 如何加速穩定與吸收、吸收部位、環境靈氣濃度要求 |
| 3 | 儲存 | 儲存部位、容量與回復特性 |
| 4 | 特性 | 轉化後靈力所帶的使用者特性——功法最鮮明的識別 |
| 5 | 再轉化 | 輸出方式與偏向 |
| 6 | 招式 | 附帶的法術或技巧（可為空，並非每門功法都完整） |
| 7 | 境界對應 | 涵蓋境界、各境表現、是否有上限 |
| 8 | 代價與限制 | 風險、副作用、與其他功法的兼容性 |

功法因淵源、種族與時代差異極大，本體系不求窮舉，只求底層邏輯一致。

## [ART-6] 六、已確立的功法

### [ART-6.1] 6-1 靈能強化術 TE-07

| **欄位** | **內容** |
| :-- | :-- |
| 基本資料 | 全名 **Terra Enforcement-07**。梵天親自創造的**速成功法**，由軍部掌握並傳授。受中央認可的國家軍隊皆可學習，封建私兵亦可 |
| 吸納 | 身體任一部位皆能吸收。速度不高，但**對環境要求極低** |
| 儲存 | 肌肉骨骼與神魂。容量在各功法中偏低，回復速度中等 |
| 特性 | 相對中正平和，帶有一絲**梵天本人的星輝之力** |
| 再轉化 | 純能量輸出與肉體強化；修煉即可強健身體素質，並可操作**靈力武器** |
| 招式 | 基本武術五式，皆為基本拳術搭配靈力衝擊 |

### [ART-6.2] 6-2 天星訣（洛克西亞家族功法）

| **欄位** | **內容** |
| :-- | :-- |
| 基本資料 | 約西元10000年大擴張時期創立，原為某大門派功法的**分支**。血脈非傳承限制，但**舊人類最適配**；梵天創造的新人類不太適合修行 |
| 吸納 | 特殊吐納與打坐方式加速吸收。靈氣濃度要求**中高** |
| 儲存 | 同時儲存於肉體、神魂與丹田。容量大，回復速度中上 |
| 特性 | 中正平和，帶有**銀河璀璨光輝** |
| 再轉化 | **靈力輸出與物質操控最強**，神魂術與肉體強化次之 |
| 招式 | **殘篇**：神魂術全數遺失，物質操控喪失部分，僅剩肉體強化與靈力輸出完整。具體招式待定 |
| 境界對應 | 一至九境，理論可至第十境。有紀錄最強者為創功祖先（第九境）；**老祖目前第八境** |
| 代價與限制 | 修行速度較慢，需求高天賦與資源。適配大部分功法。淵源於一門源自**火星遺產**的極古老功法，基於宇宙靈力底層邏輯與運作方式，故全面性與適配性極高，但攻擊性較低 |

待定：原門派名稱與現況、招式細節、老祖是否可能突破第九境。

【待定】帝國疆域內九成五以上的人口帶有新人類基因（見《新人類軍團》），因此真正「最適配」天星訣的舊人類**極為稀少**。

【限定】洛克西亞家族為罕見的**純血舊人類家系**，此即天星訣得以在家族中世代傳承的基礎。詳見《玩家出身：沒落世家》。

## [ART-APX] 附錄：觀察事項（非正典）

1. **四門功法的光譜**：TE-07 兼容一切但低天花板、天星訣全面適配但攻擊性低、金牛法典排他且綁定地理、神帝法典完整但綁定信仰——愈強的功法，綁得愈死。
