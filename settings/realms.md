## [REALM-1] 一、靈力與仙力

【公開】修仙者主動從仙界取得仙力後，將其**轉化為自身的靈力**儲存與運用。靈力是仙力經修煉者轉化後的形態。

【公開】至**第八境羽化境**，體內靈力開始朝仙力進化；完成後，其法術即成為**仙術**。

---

## [REALM-2] 二、9＋1 境界體系

【公開】修仙共分九個大境界，第十境為成仙。因第十境無名稱亦無須名稱，此體系稱為「**9＋1**」。

【公開】**第十境即成仙，但成仙不等於成神**。神明是第十境，第十境卻不必然是神明——成神另需足夠的意念與信仰（見《仙界與神明》）。

【公開】每個大境界內部分為四階：**前期、中期、巔峰、圓滿**。

| **境** | **名稱** | **形態變化** |
| :-- | :-- | :-- |
| 一 | **微塵境** | 體內初次聚起仙力，微如星塵 |
| 二 | **聚核境** | 塵埃凝成核心，臟腑骨髓隨之改造 |
| 三 | **燃星境** | 核心點燃，肉身徹底脫離凡人範疇 |
| 四 | **鑄魂境** | 神魂在星火中鑄成實形 |
| 五 | **御虛境** | 肉身與神魂足以承受虛空 |
| 六 | **星河境** | 體內靈力如璀璨星河 |
| 七 | **星穹境** | 星河鋪展為穹，內景自成天地 |
| 八 | **羽化境** | 靈力朝仙力進化，法術化為仙術 |
| 九 | **登仙境** | — |
| ＋1 | （無名稱） | 成仙 |

第九境與第十境的形態變化描述待補。

### [REALM-2.S1] 境界與修煉理解

【公開】入門階段幾乎不需理解原理，只需掌握正確方法；越高階則越需要理解修仙、仙力、自身與更深層的規律（見世界觀設定第九節）。

## [REALM-3] 三、能力錨點

【公開】以下為**人類標準**，不適用於所有種族。

| **境界** | **可做到的事** |
| :-- | :-- |
| 第五境 御虛境 | 可在太空中生存 |
| 第七境 星穹境 | 可影響一顆行星 |
| 第八境 羽化境 | 可獨自穿越仙道 |

【公開】種族差異的表現方式即在於錨點不同。已知：泰坦族身體素質極高，其太空生存門檻低於人類第五境。

第六境不設能力錨點。其餘種族的境界錨點暫不設定。

## [REALM-4] 四、玩家範圍

- **開局**：第3～5境（燃星境～御虛境）。
- **成長上限**：預期第7～8境（星穹境～羽化境）。
- 設計重心落在第5～8境；第1～2境為背景常識，第9境與第十境主要為敘事層面的存在。

第八境可獨自穿越仙道（以神識直接感知褶皺，自行導航），等同徹底擺脫對宇航公會導航與船載抵禦手段的依賴，是玩家路線上的重大里程碑。

【公開】第九境無法單憑自身抵禦仙界侵蝕；進入仙界需要第二紀元遺物、大帝聖物或戰略級護盾。

【公開】第十境即成仙；成仙者需要大量信仰支撐，方能成神。見《仙界與神明》。

## [REALM-5] 五、境界與實力梯隊

【公開】**境界衡量個體，實力梯隊衡量種族總體戰力**，兩者不可混用。

【公開】梯隊高低反映的是**全族的戰力基線與上限分布**，而非單一個體的強弱。AI GM 不得以梯隊高低直接裁定個體戰鬥結果。

### [REALM-5.S1] 對照示例

| **對象** | **境界分布** |
| :-- | :-- |
| 人族普通軍隊 | 可能只有第一境，甚至是凡人 |
| 蟲族最基礎的兵力單位 | 相當於第二境，甚至第三境 |
| 蟲巢意志的核心圈 | 平均境界可達第八～九境 |

其餘種族的梯隊與境界分布待補。

## [REALM-5A] 五之一、境界與攻防品階

【公開】修士的攻擊與防禦品階，等於其境界所屬的品階；持武器或穿裝甲時，取兩者較高者。品階不足則完全無法破防，同品之內效果無差異。

- **I 級**：第一～二境。
- **II 級**：第三～四境。
- **III 級**：第五～六境。
- **IV 級**：第七～八境。
- **V 級（頂級）**：第九境。

【公開】科技可模擬高境修士的威力、防禦、機動與感知，但無法模擬法術變化；境界越高，所需載體越大。武器、裝甲與尺度的完整規則見《仙道與科技體系》第七、九節。

## [REALM-6] 六、上限

【公開】梵天是全銀河系的戰力天花板，實力比仙界諸神更強大。

【GM】其強大屬於不合理的程度，本作中不直接寫出，僅存在於歷史文件。

【待定】梵天親手創造的十五位新人類創始人皆為**第九境登仙境**。第九境為其**設計上限**，任何創始人皆**無法突破至第十境**。第一世代（原型）與第二世代的強弱差異屬同境界內的差異。詳見《新人類軍團》。

依第四節，第九境主要為敘事層面的存在。AI GM 應將創始人視為傳說級存在，與其接觸以劇情事件處理，而非常規戰鬥。

## [REALM-6A] 六之一、壽元

【公開】凡人的壽元約 200 年。每突破一個大境界，壽元約為前一境的 1.6 倍。下列數字是各境界的理論平均值，並非上限；個體的實際壽元有增有減。

- 凡人：約 200 年。
- 第一境 微塵境：約 320 年。
- 第二境 聚核境：約 510 年。
- 第三境 燃星境：約 820 年。
- 第四境 鑄魂境：約 1,310 年。
- 第五境 御虛境：約 2,100 年。
- 第六境 星河境：約 3,360 年。
- 第七境 星穹境：約 5,370 年。
- 第八境 羽化境：約 8,590 年。
- 第九境 登仙境：約 13,740 年。

【公開】壽元會因下列情況減少：重傷或根基受創、神魂受損、突破失敗、過度透支靈力、受仙界力量侵蝕。

【公開】壽元會因下列情況增加：丹藥或天材地寶、特定功法、高靈氣濃度的環境、神明的賜福或借力。長期閉關休眠則能大幅減緩壽元的流逝。

## [REALM-6B] 六之二、突破與成長

### [REALM-6B.S1] 大境界的突破

【公開】突破大境界必須同時具備三項條件：

- 領悟：對功法、仙力或自身有新的理解，多來自經歷而非苦修。
- 契機：生死之戰、重大抉擇、神諭等關鍵事件。
- 資源：仙石、靈氣濃度足夠的修煉地點、丹藥或輔助器具。資源需求只有概略門檻，不設具體數量。

【公開】修煉的時間與高境者的指點不是必要條件，但能加速突破。

### [REALM-6B.S2] 小階的提升

【公開】同一大境界內的小階（前期、中期、巔峰、圓滿）提升只需資源與時間，不要求領悟與契機。

### [REALM-6B.S3] 大關卡

【公開】大關卡指跨越攻防品階的突破（第二境升第三境、第四境升第五境、第六境升第七境），以及第七境升第八境。只有大關卡的突破有失敗風險，其餘突破在條件齊備時必定成功。

【公開】大關卡突破失敗的後果為受傷、暫時性的境界停滯，或跌落小階。

AI GM 如何裁定突破、告知條件與處理時間跳躍，見《AI判定與系統建立規則》。
