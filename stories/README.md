# 側寫

設計者事先寫好的世界側寫短篇，用非玩家角色的視角補足設定文件寫不出的質感與細節。與戰役進度無關。

## 地位

- 側寫只是演繹。與 `settings/` 衝突時，以設定為準。
- 側寫中出現的新設定，必須先回填到 `settings/` 的對應文件，才算確立的設定。
- GM 預設不讀側寫。只有玩家指定，或需要查證時才讀（規則見 `RULE-6.9`）。

## 結構

```
stories/
  README.md                本檔
  <系列資料夾>/             以主題命名，英文小寫加底線，例如 great_rebellion/
    series.md              系列說明
    ch_001.md              第 1 章
    ch_002.md              第 2 章
```

- 一章一檔，檔名為 `ch_` 加三位數章號，各系列各自從 001 起算。
- `series.md` 只寫系列的主題、時間範圍與系列代稱，不列章節清單。章節清單只在 `index/retrieval_index.md` 的「側寫目錄」維護一份。

## 編號

- 格式：`ST-<系列代稱>-<三位數章號>`，例如 `ST-REBEL-001`。
- 系列代稱使用大寫英文與數字，不得與既有文件代碼重複（見索引第一部分），也不得與其他系列的代稱重複。
- 章是最小單位，章內不編節號。
- 編號一經發布不得更改或重複使用。章節順序有調整時，也不重編既有編號。

## 章節檔頭

每章檔案以下列格式開頭，之後接正文：

```
# [ST-REBEL-001] 章節標題
> 系列：…｜視角人物：…｜時間：梵天曆 ○ 年｜地點：…
> 可見度：【公開】｜狀態：草稿
> 涉及設定：`CHURCH-3A`、`LEGION-4`
> 摘要：一句話
> 本章新引入的設定：無
```

欄位說明：

- **時間**：可寫單一年份，也可寫範圍。
- **可見度**：每章只標一個，取該章內最敏感的等級。含【GM】內容就標【GM】，含【限定】但不含【GM】就標【限定】，其餘標【公開】；內容尚未確定者標【待定】。四種標記的定義見各設定檔的 `TAGS` 小節。
- **狀態**：「草稿」或「審定」。審定只代表設計者認可這篇文字，不代表其中的內容已成為設定。
- **涉及設定**：本章引用或牽涉的設定節號。可以留空，但只要本章引用了設定，就必須列出。
- **本章新引入的設定**：列出本章寫到、但 `settings/` 尚未記載的設定，每條標「待回填」或「已回填」。沒有則寫「無」。

## 維護

- 新增、更名或調整任何一章時，同步更新 `index/retrieval_index.md` 的「側寫目錄」。
- 回填設定後，把該條標為「已回填」，並依 `RULE-6.3` 更新索引。
- 新增系列時，先確認系列代稱沒有重複，再建立系列資料夾與 `series.md`。
